# Contributing

Entropy is a local-first desktop app. Notes and files stay on disk. If you change product or UI, read [`PRODUCT.md`](PRODUCT.md) and [`DESIGN.md`](DESIGN.md) first ([`AGENTS.md`](AGENTS.md) if you are using an agent).

## Run it

Node.js 22 or newer.

```bash
npm ci
npm start
```

## Issues

[Open an issue](https://github.com/Charlsz/entropy/issues) for bugs, questions, or ideas. Include your OS and Entropy version when something is broken.

If you think you found a security problem, open an issue anyway, or message [@Charlsz](https://github.com/Charlsz). Do not post steps that would hurt someone else's machine.

## Pull requests

Keep them small and focused. One concern per PR.

Do not add import/copy flows, automatic file moves, accounts, or clones of other apps.

Be respectful. That is the whole code of conduct.
